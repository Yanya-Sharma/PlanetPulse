# PlanetPulse — Decision Points

## DP1 — The Nudge

When a user crosses their weekly CO₂ target, PlanetPulse gives a clear but supportive warning showing how much the target has been exceeded, rather than blocking the user or using shame-based messaging. It also encourages the user to make lower-impact choices in their next activities. We chose this approach because the purpose of PlanetPulse is to help users understand and improve their habits, not punish them for exceeding a target.

## DP2 — Absurd Input

PlanetPulse detects obviously unrealistic activity quantities, such as a 500,000 km car journey, and asks the user to review the value before it is added to their footprint. The entry is not silently accepted because one accidental value could distort the dashboard, weekly progress, and historical data. At the same time, the app avoids automatically changing the user's value because unusual real-world situations should remain under the user's control.

## DP3 — The Week

PlanetPulse defines a week as Monday through Sunday, providing a consistent weekly cycle for calculating targets and progress. During the week, the dashboard shows the CO₂ already recorded, the remaining amount relative to the target, and whether the target has been exceeded. We chose a fixed Monday-to-Sunday cycle so users can easily understand when their weekly target begins, how much progress they have made, and when the cycle resets.
